## 工作区

所有已有和未来的全局及组件设置项按对象、用途或状态分组。同一对象的尺寸、颜色、排版和动效等相关设置集中展示，不按属性类型拆散；多状态设置在对应状态内集中展示。整理已有工作区时同步归并相关旧项，保留配置兼容、恢复继承、撤销重做及保存导入能力。界面分组不改变四端尺寸与亮暗外观的存储归属。

- 左侧按分组完整展开全局编辑项：种子色与全部语义颜色、字体和完整语义字阶、四端公共尺寸与控件内边距、三档动画时长与曲线、弹簧、前景对比度，以及材质质量、透明度降级、淡入阶段占比、配方、背景、染色、水平/垂直模糊、边框和多层阴影。颜色、动效与材质按亮暗方案独立编辑；字阶与尺寸按当前真实设备独立编辑。每项保留恢复继承能力。
- 中间通过两层 HyperTabBar 切换组件：上层为基础、容器、内容、输入、反馈、导航分类，下层显示当前分类的组件。两层使用中文短名称和图标，空间不足时横向滚动；每个分类记住上次选中的组件，完整类名及说明保留在预览页。也可进入完整 Demo，切换横竖屏与辅助文字缩放。画布尺寸沿用预览测试预设，单位为逻辑像素；不是机型官方规格。
- 右侧根据当前组件展示 Button、Tag、Chip、Card、TextField、Select、Menu，以及新增的 Badge、Divider、Progress、Radio、Checkbox、Switch 设置，修改当前端尺寸、当前亮暗方案的通用背景/前景和多层彩色阴影。可恢复单项继承或重置当前组件。
- 窄窗口通过顶部工作区按钮切换全局、组件或预览视图，不把真实桌面设备重新分类。

颜色可以继承默认、绑定 primary/surface/textPrimary/outline 或输入 #AARRGGBB。语义引用会跟随当前方案的主题色变化。阴影有独立不透明度、偏移、模糊和扩散参数；空阴影列表表示显式关闭。

## 保存与应用

“保存”写入本机应用存储中的命名主题库；“另存为”可用新名称保存。“导入/导出 JSON”通过 file_picker 选择和保存本地文件。Web 的主题库位于浏览器存储，导出通过下载完成。

编辑主题仅影响预览。“下次启动使用”单独保存外壳启动配置，重启进程后才应用；不会即时替换当前工作区的主题。切换主题、新建、导入或系统请求退出时检查未保存改动。

撤销/重做支持工具栏和 Ctrl+Z / Ctrl+Shift+Z；Ctrl+S 保存。滑块一次拖动合并为一步。

## 文件与实现范围

JSON 使用 `formatVersion: 1` 与 `base: lemon-hyper-v1`。亮暗视觉分开，四端尺寸共享；只保存显式覆盖，默认数值与空覆盖对象省略。恢复默认移除字段，`shadows: []` 保留显式关闭。语义色保存引用，不展开成默认颜色。未知版本、基础标识和字段拒绝导入，避免默默丢失配置。

第一版序列化位于 example 的强类型 `EditorThemeDocument` 及其嵌套模型，通过现有 copyWith 转换为 HyperThemeData。尚未开放所有组件字段，也尚未为库内所有 ThemeData/Style 补齐通用 fromJson/toJson；当前导出 JSON 仅保证本编辑器开放字段完整往返。后续迁入公共序列化模块时需保留本格式的迁移入口。

Button 已按真实样式接入禁用背景和前景、状态层颜色与三种透明度、边框、进度颜色和线宽、动画时长；这些字段按明暗方案及六种按钮变体分别保存，通用设置供变体继承。四端最小宽度、小／中／大高度与内边距、图标及进度尺寸进入设备规格。通用强调色按变体派生底色或前景，单独变体背景覆盖优先。JSON 的 `buttonStyle` 和 `buttonMetrics` 均为可选字段，旧文件继续支持。

暂未开放全部组件字段、实例 Style、任意字体资产、Dart 代码导出、“只看已修改”过滤。基础主题改变时须升级 base 并提供明确迁移，不能复用原标识偷偷改变旧主题外观。

材质新增入口仍在统一 HyperSurfaceMaterial 配方与 HyperMaterialSurface 渲染层；编辑器只映射现有配方，不在各组件添加新渲染路径。本版不加入流体玻璃。

Widget 测试验证编辑器布局、预览隔离、撤销、保存打开与默认规格；模拟画布不代表四端实机或视觉验收。原 Demo 中主动创建局部主题或实例 Style 的示例仍按原有覆盖优先级显示，可能覆盖当前全局编辑结果。


Button 各变体、Card、TextField 与 Menu 的背景支持继承默认、纯色、线性 / 径向 / 扫描渐变和无填充。渐变可增删颜色节点、调整节点位置（0–1）与方向（0 度向右、90 度向下），至少保留两个节点，位置非递减。配置保存在对应明暗方案的组件 fillKind / gradient 字段；旧 buttonStyle.gradient 文件继续支持。按钮通用背景显式类型由各变体继承，独立变体覆盖优先；旧通用强调色仍保留按变体派生规则。

各组件边框支持继承默认、实线、虚线、点线及无边框。虚线长度与间隔可调整，宽度 0 完全关闭。背景类型、边框和数值属性均提供用途说明；保留恢复继承、撤销重做与保存导入。
按钮尺寸区统一使用小 / 中 / 大档位切换，高度、最小宽度、固定宽度及内边距按设备和档位独立保存；圆角、图标和进度尺寸只显示一份。自适应宽度允许内容增宽，固定宽度仍受父约束和最小宽度约束。旧 buttonHeight 对应中号最小高度，旧 minimumWidth 对应中号最小宽度，原 JSON 继续兼容。

渐变类型在各组件共用编辑入口中切换，节点与位置保留。线性提供方向；径向提供中心（-1 到 1）与相对短边的半径；扫描提供中心、起止角度与整体旋转（角度单位为度，至少保留 0.1 度角度范围）。旧文件缺少 kind 时按线性读取；继承的渐变类型和参数会被正确显示，底层继续复用 Flutter Gradient 和 HyperFill。

## TextField 组件工作区

尺寸按当前设备独立保存：最小高度、圆角、内边距、图标尺寸、操作区宽度、标签间距和错误浮层最大宽度。亮暗方案分别保存输入、占位、标签和计数字号、图标与文字颜色、光标宽度与圆角、状态过渡时长，以及悬停、焦点、错误边框和禁用前景颜色。沿用背景、渐变、边框与阴影编辑。每项可恢复继承；重置清除当前方案外观和当前设备规格。支持草稿持久化及 JSON 导入导出；旧文档缺省字段继续继承主题。行为通过完整 Demo 交互验证。

TextField 边框按默认、悬停、聚焦、错误、禁用分别编辑，支持实线、虚线、点线、无边框、颜色、宽度和虚线间距。状态未覆盖的形态继承默认边框，颜色保留各状态的语义默认值；错误优先于聚焦，禁用最后覆盖。各状态可独立恢复继承，旧版状态颜色字段仍兼容。

TextField 工作区按对象分组：输入框表面、各状态边框、输入文字、占位文字、标签、字数计数、图标与操作区、光标、错误提示、禁用状态和状态过渡。同一对象的字号、颜色与间距集中展示，分组只调整编辑入口，不改变四端尺寸及亮暗外观的存储归属。

表面设置统一置于编辑项末尾：背景、材质、圆角、各状态边框和阴影集中展示。Button 已按按钮布局与图标、文字、禁用状态、交互反馈、加载进度、状态过渡和底部表面设置组织；进度尺寸、颜色与线宽集中，圆角移到表面组。

全局工作区按对象归并：主题与强调色、字体字阶与文字颜色、页面布局、导航工具栏、控件布局与触控、图标、各语义状态、前景对比度、三档动效与弹簧。每档动效的时长和曲线相邻。页面背景、普通/抬升/弱化表面、控件轮廓、浮层表面和材质质量、降级、配方与阴影统一放在底部；字段和持久化格式保持兼容。

输入框提供聚焦阴影/焦点环编辑，按钮提供悬停、聚焦、按下与禁用阴影；各项支持多层颜色、透明度、偏移、模糊与扩散，null 继承普通阴影，空列表关闭。按钮状态优先级为禁用、按下、聚焦、悬停、默认。所有入口集中在底部表面设置区，按钮通用配置由变体继承。

Button 的交互变换按悬停、聚焦和按下分别设置水平/垂直位移与缩放，集中在交互变换组。默认无覆盖（位移 0，缩放 1），只有显式设置才生效；通用设置由变体继承，变体和实例可独立覆盖。位移为逻辑像素，垂直负值上浮、正值下沉；变换只作用于绘制，不改变布局或命中区域。时长与曲线继承按钮动效及全局 Motion，系统减少动画时保持零位移与原尺寸。

滑块拖动期间不重复序列化撤销快照；手势开始记录原始文档，结束时比较并提交一条撤销记录。每次编辑状态更新后失效亮暗主题解析与文档编码缓存，同一更新内的全局、组件与预览共享解析结果，未保存状态复用编码结果。保留实时预览、撤销重做和持久化语义。

## Select 组件工作区

Select 入口沿用 hyper-select-fields 页面 id。触发文字、箭头、选项布局与文字、各选项状态颜色、多选标签、搜索、面板与过渡按对象分组；底部可切换触发按钮和选项面板，分别配置背景、边框及阴影，面板和选项圆角也置于底部。尺寸按设备独立保存，外观按亮暗方案保存，支持 JSON 往返、恢复继承与重置。Select 触发按钮通过 HyperSelectStyle.buttonStyle 覆盖，实例 buttonStyle 优先；选项表面继续复用 resolveHyperMenuSurface，不影响 Autocomplete 独立主题。Button 与 TextField 的编辑范围说明分别描述本组件的真实编辑能力。

Select 触发器新增按设备保存的最小高度、水平/垂直内边距、圆角和最小命中尺寸；文字与禁用颜色、叠加色和三态透明度、位移缩放、过渡时长以及三态/禁用阴影复用按钮样式。布局、文字与反馈集中在触发器设置，圆角及状态阴影位于底部触发按钮表面组。配置只作用于 Select 触发器，普通 Button 和 Autocomplete 保持独立；默认变换和状态阴影均不启用。

触发器组统一管理 Select 与 Autocomplete 的共用布局和外观；触发圆角移到顶部布局组。自动填充跟随设备高度、内边距和圆角，共用文字、背景、边框、禁用配色、状态阴影、位移缩放及过渡。箭头和按钮交互叠加属于下拉专属，在界面明确标记；自动填充的显式主题和实例输入样式仍优先。编辑器也同步选项面板和搜索配置到 Autocomplete。

选项面板的选中图标集中配置显示/隐藏、前置/后置、图标（对勾、双对勾、圆形、星形）、独立颜色、尺寸和间距；隐藏时移除图标占位，保留选中配色。Select 与 Autocomplete 同步，支持恢复继承和保存回读。默认保持尾部对勾。

## Chip 组件工作区

沿用 hyper-chip 页面 id，通用、选中、悬停、聚焦、按下和禁用状态分别编辑。通用布局、图标头像和删除区尺寸按设备独立保存；各状态的文字、头像透明度、选中图标及位置、删除图标、颜色和过渡分别绑定 HyperChipStyle。背景、圆角、边框和多层阴影集中在底部。支持导入导出、恢复继承和当前状态重置；局部/实例样式仍优先，多选摘要的紧凑尺寸为明确的组合覆盖。

Chip 标签边框与 Button 共用边框编辑项，支持继承、实线、虚线、点线和无边框；颜色、宽度、虚线长度及间隔按各交互状态独立保存。组件通过 HyperChipStyle.boxBorder 覆盖，旧 borderColor / borderWidth 配置继续兼容。

Chip 配色支持中性、浅色、实色、描边和无底色。标签基色可引用全局主色或自定义；背景、边框和文字减淡比例各为 0–100%，0 为原色、100 为表面色（实色文字从解析后的前景色混合）。实色文字支持自动对比色和白色。各状态、亮暗方案独立保存；显式背景、前景和边框优先于自动配色。减淡采用颜色混合，不改变整体透明度。

编辑范围选择统一使用带名称下拉项：Button 的外观变体与 Chip 的状态覆盖各自明确继承范围，配色归入外观配色，不与交互状态混用。编辑对象和尺寸档位保持各自独立。

Button 与 Chip 均通过状态覆盖选择显示当前状态。Button 按外观变体、状态覆盖两层组织；悬停、聚焦、按下各自集中显示反馈强度、位移缩放和阴影，禁用显示前景背景和阴影。尺寸与共用外观留在通用状态，状态重置不修改其他状态或变体。

已接入工作区的 TextField、Select/Autocomplete/Dropdown、Button、Chip 统一按状态覆盖选择显示属性。Select 先选触发器或面板，两者保留独立状态选择；触发器支持悬停、聚焦、按下、禁用，面板支持选中、活动、禁用。TextField 支持悬停、聚焦、错误、禁用。Card 与 Menu 现有工作区仅包含共用属性，不提供无对应配置的状态入口。对象重置和状态重置仅作用于所选范围。全局语义颜色是各组件共享的色源，不作为单个组件的交互状态覆盖。

Tag 标签工作区复用 Chip 的配色规则，支持中性、浅色、实色、描边、无底色、基色、自动/白色前景及三项减淡比例；背景支持纯色、渐变、无填充，边框支持实线、虚线、点线、无边框，阴影支持多层配置。尺寸使用独立 tagMetrics 按四端保存，外观使用 tag/tagEmphasized/tagDisabled 按亮暗保存。先选通用或强调变体，再选通用或禁用；禁用配置由所有变体共用，Tag 不提供 Chip 的选择、删除、头像和悬停/按下交互设置。
