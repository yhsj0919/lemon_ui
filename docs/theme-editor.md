# Demo 主题编辑器（第一版）

运行 `example` 时手机和手表默认进入完整 Demo，桌面和平板进入主题工作室；入口沿用稳定设备解析，不随窗口缩放改变。编辑器外壳优先使用 Hyper 控件，预览拥有独立 MaterialApp、Navigator、设备解析与主题作用域。

## 工作区

- 左侧按分组完整展开全局编辑项：种子色与全部语义颜色、字体和完整语义字阶、四端公共尺寸与控件内边距、三档动画时长与曲线、弹簧、前景对比度，以及材质质量、透明度降级、淡入阶段占比、配方、背景、染色、水平/垂直模糊、边框和多层阴影。颜色、动效与材质按亮暗方案独立编辑；字阶与尺寸按当前真实设备独立编辑。每项保留恢复继承能力。
- 中间通过两层 HyperTabBar 切换组件：上层为基础、容器、内容、输入、反馈、导航分类，下层显示当前分类的组件。两层使用中文短名称和图标，空间不足时横向滚动；每个分类记住上次选中的组件，完整类名及说明保留在预览页。也可进入完整 Demo，切换横竖屏与辅助文字缩放。画布尺寸沿用预览测试预设，单位为逻辑像素；不是机型官方规格。
- 右侧独立选择 Button、Card、TextField、Menu，修改当前端尺寸、当前亮暗方案的通用背景/前景和多层彩色阴影。可恢复单项继承或重置当前组件。
- 窄窗口通过顶部工作区按钮切换全局、组件或预览视图，不把真实桌面设备重新分类。

颜色可以继承默认、绑定 primary/surface/textPrimary/outline 或输入 #AARRGGBB。语义引用会跟随当前方案的主题色变化。阴影有独立不透明度、偏移、模糊和扩散参数；空阴影列表表示显式关闭。

## 保存与应用

“保存”写入本机应用存储中的命名主题库；“另存为”可用新名称保存。“导入/导出 JSON”通过 file_picker 选择和保存本地文件。Web 的主题库位于浏览器存储，导出通过下载完成。

编辑主题仅影响预览。“下次启动使用”单独保存外壳启动配置，重启进程后才应用；不会即时替换当前工作区的主题。切换主题、新建、导入或系统请求退出时检查未保存改动。

撤销/重做支持工具栏和 Ctrl+Z / Ctrl+Shift+Z；Ctrl+S 保存。滑块一次拖动合并为一步。

## 文件与实现范围

JSON 使用 `formatVersion: 1` 与 `base: lemon-hyper-v1`。亮暗视觉分开，四端尺寸共享；只保存显式覆盖，默认数值与空覆盖对象省略。恢复默认移除字段，`shadows: []` 保留显式关闭。语义色保存引用，不展开成默认颜色。未知版本、基础标识和字段拒绝导入，避免默默丢失配置。

第一版序列化位于 example 的强类型 `EditorThemeDocument` 及其嵌套模型，通过现有 copyWith 转换为 HyperThemeData。尚未开放所有组件字段，也尚未为库内所有 ThemeData/Style 补齐通用 fromJson/toJson；当前导出 JSON 仅保证本编辑器开放字段完整往返。后续迁入公共序列化模块时需保留本格式的迁移入口。

暂未开放状态/变体精调、实例 Style、任意字体资产、全部语义色与 Motion、Dart 代码导出、“只看已修改”过滤。基础主题改变时须升级 base 并提供明确迁移，不能复用原标识偷偷改变旧主题外观。

材质新增入口仍在统一 HyperSurfaceMaterial 配方与 HyperMaterialSurface 渲染层；编辑器只映射现有配方，不在各组件添加新渲染路径。本版不加入流体玻璃。

Widget 测试验证编辑器布局、预览隔离、撤销、保存打开与默认规格；模拟画布不代表四端实机或视觉验收。原 Demo 中主动创建局部主题或实例 Style 的示例仍按原有覆盖优先级显示，可能覆盖当前全局编辑结果。
